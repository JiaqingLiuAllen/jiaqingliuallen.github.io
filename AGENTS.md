# Personal website workflow

- Do not push changes unless the user explicitly requests a push.
- After each website update, build the site, verify the affected pages, and show a local browser demo.
- Preserve factual research, education, publication, and contact information. Do not invent positions, contributions, availability, or CV content.
- Keep publication metadata in `_bibliography/papers.bib`; shared visual styles are in `_sass/_academic.scss`.
